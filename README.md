## 🚀 Características

- 🔐 **Inicio de sesión y registro** por estudiante (nombre, curso, número de fila)
- 📚 **Soporte multi-curso**: 901, 902, Décimo y Once
- 🧮 **Cálculo automático** de notas:
  - Actividades + Puntos Extra → **60%**
  - Autoevaluación → **10%**
  - Trimestral → **20%**
  - Lectura Crítica → **10%**
- 📊 **Resumen visual** por período
- 💾 **Persistencia local** (localStorage)
- 🎨 **Diseño moderno** con tema oscuro
- 📱 **Responsive** (adaptable a móviles)
- 📖 **Guía de uso** integrada
