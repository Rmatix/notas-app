## 🚀 Características

- 🔐 **Inicio de sesión y registro** por estudiante (nombre, curso, número de fila)
- 📚 **Soporte multi-curso**: 901, 902, Décimo y Once
- 🧮 **Cálculo automático** de notas:
  - Actividades + Puntos Extra → **60%**
  - Autoevaluación → **10%**
  - Trimestral → **20%**
  - Lectura Crítica → **10%**
- 📊 **Resumen visual** por período
- 💾 **Persistencia local** (localStorage)
- 🎨 **Diseño moderno** con tema oscuro
- 📱 **Responsive** (adaptable a móviles)
- 📖 **Guía de uso** integrada

## 🛠️ Instalación y uso

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/Rmatix/notas-app.git
```

1. Abre index.html en tu navegador.
2. Regístrate con tu nombre, curso y número de fila.
3. Agrega tus actividades y calcula tus notas.

---

📖 Guía rápida

Paso Acción
1 Regístrate o inicia sesión
2 Agrega materias si faltan
3 Registra actividades con nota (0-5) y fecha
4 (Opcional) Agrega puntos extra
5 Presiona "FINALIZAR NOTA MATERIA"
6 Ingresa Autoevaluación, Trimestral y Lectura Crítica
7 Presiona "NOTA DEL TRIMESTRE"
